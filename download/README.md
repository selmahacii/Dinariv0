# Télécharger Dinari (Android)

## Lien direct de l'APK

| Fichier | Pour quels téléphones | Lien de téléchargement |
|---|---|---|
| **Dinari-v1.0.0-arm64.apk** | La quasi‑totalité des téléphones actuels (64 bits) | https://github.com/selmahacii/Dinariv0/raw/main/download/Dinari-v1.0.0-arm64.apk |
| Dinari-v1.0.0-arm32.apk | Anciens téléphones 32 bits | https://github.com/selmahacii/Dinariv0/raw/main/download/Dinari-v1.0.0-arm32.apk |

> En cas de doute, prendre **arm64**.

## Installation sur Android

1. Ouvrir le lien ci‑dessus depuis le téléphone → le `.apk` se télécharge.
2. Ouvrir le fichier téléchargé.
3. Android demande d'autoriser l'installation depuis cette source :
   **Paramètres → Applications → Accès spécial → Installer des applis inconnues**
   → activer pour le navigateur (Chrome) ou le gestionnaire de fichiers.
4. Revenir sur le fichier, appuyer sur **Installer**.
5. Ouvrir **Dinari**.
